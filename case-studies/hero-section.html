From design to code: Hero Section in HTML & CSS

My first step from designing in Figma to building in the browser. I took the hero of my own portfolio and rebuilt it from scratch with plain HTML and CSS, without frameworks or page builders. The goal: understand how a layout really works, and make it look good on every screen size.

What I practiced

Semantic HTML

A clear structure with header, nav, main, section and figure, and only one h1 per page.

Flexbox

The navigation bar: logo on the left, links on the right, everything centered vertically.

CSS Grid

The two-column hero layout, with the text column a little wider than the photo.

CSS variables

Colors, fonts and the arch radius are defined once in :root and reused everywhere.

Fluid typography

The headline grows with the screen using clamp(), from 40px on phones to 68px on desktop.

Responsive design

Two media queries (860px and 480px) switch to one column, move the photo up and simplify the navigation.

Shapes without extra HTML

The red arch behind the photo is a ::before pseudo-element placed with position and z-index.

Accessibility

Alt text, an aria-label for the navigation and visible :focus-visible styles for keyboard users.

A look at the code

The core of the layout: one grid rule for desktop, one media query for small screens.

/* Two columns: text wider than photo */
.hero-grid {
  display: grid;
  grid-template-columns: 1.3fr 1fr;
  gap: 48px;
  align-items: center;
}

/* Headline grows with the screen */
.hero-text h1 {
  font-size: clamp(40px, 6vw, 68px);
}

/* Phones: one column, photo on top */
@media (max-width: 860px) {
  .hero-grid { grid-template-columns: 1fr; }
  .hero-photo { order: -1; max-width: 280px; }
}
